Der (vermeintliche) Nutzen
Wie stets in unserer hochentwickelten Gesellschaftsform ist
 Bequemlichkeit das maßgebliche Argument, das dem vermeintlich
 mündigen Bürger vorgelegt wird, wenn es um die Einführung neuer
 Technologien geht. Er wird sein Gehirn ein weiteres Mal weniger
 nutzen müssen und erfährt eine weitere digitale Lösung für seinen
 Alltag. Zudem wird es im Alltag auch sicherer werden, wenn ein
 jeder die digitale ID einsetzt. Straftäter können schneller identifi-
 ziert werden. Grenzen können leichter geschützt werden. Für viele
 Bürger, die nach mehreren Krisenjahren in Folge schlicht Ruhe
 wollen, klingt das verlockend. Und wenn es dazu eine digitale ID
 braucht, braucht es eben eine digitale ID. Punkt.
